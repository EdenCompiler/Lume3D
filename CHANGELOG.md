# Changelog

## 1.0.0 — 2026-08-13

- added the integrated GLFW window, input, timing, and OpenGL 3.3 runtime;
- added hierarchical scenes, empty nodes, meshes, cameras, and three light types;
- added custom geometry with generated normals and box, plane, and sphere primitives;
- added RGBA/stb_image textures and basic/Lambert materials;
- added English runtime diagnostics and an optional log callback;
- added static/shared CMake builds, installation metadata, examples, tests, and bilingual documentation.
